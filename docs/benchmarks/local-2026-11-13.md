### Startup investigation

The first PTY run measured **2,545.9 ms** for 100 MB open, against the historical
171 ms. Open timing instrumentation showed `model=539.2 ms` and
`terminal=2,541.3 ms`; the extra time was crossterm's 2 s keyboard-enhancement
query on `TERM=dumb`, which cannot answer it.

`TerminalSession` now skips terminal queries when `TERM=dumb` or
`ANVIL_SKIP_TERMINAL_QUERY` is set. The re-run above measures **235.3 ms**.
This is still above the historical 171 ms but no longer a multi-second startup
stall; the difference needs a reference-machine comparison, not a local gate
failure.
