# Local Performance Baseline — 2026-11-13

Status: local workstation run. This is **not** the Ryzen 7 5800X reference
machine, so it does not satisfy the reference-machine exit gate. It is recorded
to detect regressions and to preserve the current local numbers.

## Machine

- CPU: 12th Gen Intel(R) Core(TM) i7-12700H, 20 logical CPUs
- OS: Linux 7.3.3-1-cachyos
- Build: release benches; Go default test profile
- Filesystem: local NVMe

The reference-machine gate remains **skipped** until the documented Ryzen 7
5800X host runs the full suite. Do not promote this file to gate evidence.
