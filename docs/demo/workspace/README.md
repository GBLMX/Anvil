# Anvil demo

Anvil is a Linux-first terminal editor with a selection-first core, a per-session
policy gateway, and a capability-scoped plugin host.

```rust
fn main() {
    println!("hello from Anvil");
}
```

- fuzzy file open
- workspace tree and native watch status
- LSP hover, completion, rename, and code actions
- read-only Git views and hunk staging
- themes, splits, and session restore
