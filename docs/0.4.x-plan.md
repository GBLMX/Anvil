# 0.4.x Feature Plan

Status: active. `0.3.0 → 0.4.0` was the maintenance train; `0.4.0` released on
2026-11-01. Feature development resumes on the `0.4.x` line.

One release carries one bounded feature slice plus its tests and documentation.
A slice is not complete while it needs a follow-up release to be usable.

## 0.4.1: Workspace tree watcher

- Status: released as `0.4.1` on 2026-11-01; installed binaries verified.
- Gateway `sys.read_dir_signature` with `fs.read` and `openat2` confinement.
- Root plus expanded-directory polling; 500 ms poll and 500 ms debounce.
- Coalesced `TreeChanged`; 256-directory cap; `Files · stale` and
  `Files · watch limit`.
- Generation-scoped snapshots preserve selection and expansion; background
  refresh does not steal focus; missing new expansion queues a follow-up.
- Follow-up: [#9](https://github.com/GBLMX/Anvil/issues/9) remains open for
  exact name tracking after an external rename.
- Add `INSTALL.md` and verify the installed sibling binaries.
- Install guide: [INSTALL.md](../INSTALL.md).
- ADR: [0018](adr/0018-workspace-tree-watch.md).

## 0.4.2: Syntax highlighting coverage

- Status: not started.
- Replace extension-only detection with a static language registry.
- Add TOML, Go, Bash, Python, YAML, JSONC, Makefile, and Dockerfile grammars.
- Detect extensionless `Makefile`, `Dockerfile`, and `go.mod` by filename.
- Remove the Rust keyword walker from other languages.
- Unsupported formats remain plain text; 256 KiB cap remains.

## 0.4.3: Markdown highlighting

- Status: not started.
- Use `tree-sitter-md` block and inline grammars without pulling a second
  tree-sitter runtime.
- Add heading, link, code, emphasis, list, quote, table, and frontmatter
  classes.
- Highlight fenced code with the nested language when available.
- Define overlay precedence and test malformed fences, nested lists, and
  frontmatter.

## 0.4.4: Plugin runtime slice

- Status: design gate; not started.
- Turn the empty plugin host into a tested Lua/TS runtime path.
- Add the capability table and gateway control-socket registration.
- Wire activation, concurrency, and lifecycle from
  [ADR-0017](adr/0017-plugin-activation-and-lifecycle.md).
- No editor-process plugin runtime.

## 0.4.5: Protocol and session boundaries

- Status: not started.
- Version the gateway protocol and add compatibility tests.
- Extract `anvil-session` from the TUI so a frontend can use the kernel without
  forking the terminal UI.
- Keep the interim TUI keymap separate from kernel semantics.

## Release gates

Every `0.4.x` release must satisfy the gates in
[RELEASE.md](../RELEASE.md), update `CHANGELOG.md`, `ROADMAP.md`, the relevant
known issues/ADR, and pass an installed-binary smoke test.
