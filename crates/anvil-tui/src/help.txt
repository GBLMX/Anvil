Anvil help

Launch
  anvil --workspace <dir> [file]
  File paths are workspace-relative. Missing gateway: file I/O is refused.

Normal mode
  h j k l / arrows    move
  w / b / e           next / previous word, word end
  {count}w/b/e        count word motions; 3x, 2dd, 2yy
  ciw / ci" / ci'     change inner word / quoted text
  "a{yy,p}            named yank/put register; "_" is blackhole
  Home / End          line start / end
  q{reg} / @{reg}     record macro / replay macro; @@ repeats
  s                   select all occurrences of the word under the cursor
  Alt-s               split the selection into one cursor per line
  C / Alt-C           add a cursor below / above on the same column
  Ctrl-w v            open a vertical split
  Ctrl-w h / l        focus the left / right pane
  Ctrl-w q            close the split
  Space e             file tree (h/l/Enter expand or open, H toggles hidden)
  tree a / A         create file / folder in the tree
  tree r / m / c     rename / move / copy the selected entry
  tree d             delete the selected entry recursively
  Space r             rename symbol
  Space a             code actions / quick fixes
  Space s             document symbols
  Space S             workspace symbols
  Space F             format the current document
  Space f             fuzzy file finder; type to filter, Enter opens
                      selected file previews beside the list when wide and
                      below it when narrow; icons mark file types
  gd                  go to definition
  gr                  list references and jump on Enter
  gh                  highlight symbol uses in the current buffer
  gi / go             list incoming / outgoing calls
  za / zM / zR        toggle / close all / open all folds
  ]d / [d             next / previous diagnostic
  Alt-j / Alt-k      next / previous parsed stdin location
  Enter              open selected stdin location
  K                   hover documentation
  i a A o O           insert before / after / line end / below / above
  x                   delete character
  dd                  delete line
  dw / db / de        delete word forward / back / end
  yy                  yank line
  yw / yb / ye        yank word forward / back / end
  p                   put unnamed register
  u / Ctrl+r          undo / redo
  /pattern            incremental search; Enter accepts, Esc restores cursor
  :undo / :redo       undo / redo via Ex command
  n / N               next / previous match
  Ctrl-r / Ctrl-w / Ctrl-c  regex / whole-word / case toggles in search
  :replace text       replace current match
  :replace-all text   replace all matches atomically
  :prefix<Tab>        complete commands, theme args, plugin IDs; Esc closes
  :w                  save
  :w file             save as
  :wa                 save all modified buffers
  :s/old/new/[g]      replace first / all on current line
  :%s/old/new/g       replace all in the file
  :wq                 save and quit
  :e file             open or switch file
  :bn / :bp           next / previous buffer
  :new                create an empty buffer
  :bd [n] / :bd!      close current or indexed buffer; ! discards
  :q                  quit, or close help
  :q!                 force quit, or close help
  :conflict-recover   load the conflicted swap into this buffer
  :conflict-discard   discard the swap and keep the current buffer
  :git-diff           show the current file diff against HEAD
  :git-diff --staged  show the staged diff against HEAD
  :git-hunk-next/prev jump between diff hunks
  :git-stage-hunk     stage the hunk at the cursor
  :git-unstage-hunk   unstage the hunk at the cursor
  :cq                 quit with exit status 1
  :tree               toggle the workspace file tree
  :reconnect          restart the gateway and re-handshake
  :git-blame          show blame for the current file
  :git-conflicts      list unmerged paths
  :git-conflict-base   preview index stage 1 (base)
  :git-conflict-ours   preview index stage 2 (ours)
  :git-conflict-theirs preview index stage 3 (theirs)
  :git-resolve-ours  replace and stage with index stage 2
  :git-resolve-theirs replace and stage with index stage 3
  :git-resolve-ours! / :git-resolve-theirs! discard modified buffer
  :search-project Q   ripgrep the workspace; Alt-j/k selects, Enter opens
  :search-cancel      clear project search results
  :lsp-start          ensure the detected language server is active
  :lsp-stop           stop the active language server
  :format              format the current document
  :symbols             document symbols
  :problems           toggle the problems panel
  :plugin-start       start the debug plugin host
  :plugin-list        open installed-plugin manager (enable/uninstall/rollback)
  :plugin-oom         start host with a 300 MB allocation probe
  :plugin-exec        exercise sys.exec (returns unsupported)
  :plugin-stop        stop the plugin host
  :plugin-enable <id> re-enable a disabled plugin and start it
  :settings           edit scroll margin, search case, and inlay hints
  :theme [name]        list or switch and remember built-in theme
  :theme-auto [dark] [light]  match background and remember
  :theme-save         re-save the runtime theme choice
  :pkg install <url>  download, review, and install a signed plugin package
  :pkg install-file <package> <signature> <key>  review and install a local package
  :help               this page

Insert mode
  Esc                 return to normal mode
  Ctrl+Space          LSP completion popup
  . / :               auto-trigger completion in insert mode
  Enter               newline
  Tab / Shift-Tab     next / previous snippet placeholder or indent
  Backspace / Delete  delete grapheme
  arrows / Home / End move

Help is read-only. :q returns to the previous buffer.
